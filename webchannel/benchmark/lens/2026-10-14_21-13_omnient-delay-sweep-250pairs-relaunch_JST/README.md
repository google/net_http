# Omnient 250-pair-per-delay benchmark

[Report](report.md) · [Connection reuse audit](connection-reuse-audit.md) · [Artifacts](artifacts.md) · [Infrastructure and resumption audit](infrastructure-audit.md)

Requested delays: 0, 50, 100, 150 and 200 ms. Each delay retains 250 OFF/ON measurement pairs. The main report includes eligible initial early POST HTTP 400 pairs and applies the 20 ms full-precision handshake-difference threshold and verified fresh HTTP/2 transport requirement. Startup failures, original evidence, review and safe resumption are documented separately in the infrastructure audit.
